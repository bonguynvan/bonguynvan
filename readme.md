### Hi, I'm Bo

I'm a developer in Vietnam. I've spent most of my career on securities trading platforms, and
these days I mostly work on open-source tools for apps that show a lot of live data.

What I'm working on:

- [**TradeCanvas**](https://github.com/bonguynvan/tradecanvas): trading charts for the web, on
  Canvas 2D or WebGL, with no dependencies. Indicators, drawing tools, live feeds and orders on
  the chart. Docs and a live demo at [tradecanvas.dev](https://tradecanvas.dev).
- [**bo-grid**](https://github.com/bonguynvan/bo-grid): a fast Svelte 5 data grid for live
  price boards, with a web component for other frameworks.
- [**densa**](https://github.com/densa-rs/densa): a Rust toolkit for apps that show a lot of
  live data: live Arrow tables, a GPU data grid and charts, widgets and docking. Plus
  [densa studio](https://github.com/densa-rs/densa-studio), an app built on it for exploring
  Parquet, CSV and live streams with SQL.
- [**Sveltier**](https://github.com/sveltier/sveltier): a UI framework for Svelte 5, designed
  to be easy for AI coding agents to use. Still alpha.
- [**Fansipan**](https://github.com/bonguynvan/fansipan): an open-source desktop trading
  terminal for securities, for any market and any broker. Rust, Tauri and Svelte.

I write mostly TypeScript, Svelte and Rust.
